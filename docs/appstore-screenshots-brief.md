# Postit 앱스토어 스크린샷 요청 (Claude Design 전달용)

이전에 만든 **Postit Design v1**(디자인 토큰·컴포넌트·맥/아이패드/아이폰 시안)을 그대로 사용해서,
App Store에 올릴 **마케팅 스크린샷 세트**를 만들어 주세요.
목표는 "이 앱이 맥·아이패드·아이폰에서 각각 어떻게 쓰이는지"가 한 장씩 넘겨 보기만 해도 이해되는 것입니다.

---

## 1. 앱 한 줄 소개

**Postit** — 책상 위 포스트잇 한 장을 맥·아이패드·아이폰에서 똑같이. iCloud로 자동 동기화되는 할 일 포스트잇.
- 한 줄 적고 체크하면 끝. 날짜별로 정리되고, 못 끝낸 일은 다음 날 Today로 넘어옴
- 맨 위 고정, 마감일·알림, 검색, 포스트잇 여러 장(교회·학교·집 등), 다크 모드

## 2. 규격 (App Store Connect 기준, 세로 기준)

| 기기 | 크기(px) | 장수 |
|---|---|---|
| iPhone 6.9" | 1320 × 2868 (세로) | 6장 |
| iPad 13" | 2064 × 2752 (세로) 또는 2752 × 2064 (가로) — 보드는 **가로** 권장 | 5장 |
| Mac | 2880 × 1800 | 5장 |

- 각 장은 **위쪽 1/4: 큰 헤드라인 + 작은 설명 한 줄**, 아래 3/4: 기기 화면(기기 프레임 포함 또는 화면만 크게).
- 배경은 따뜻한 책상 톤(라이트 #E4E1DA 계열, 다크 장은 #1C1B19 계열) 위에 앱 화면. 과한 그라데이션·네온·3D 금지.
- 글꼴: 헤드라인은 SF Pro / Apple SD 산돌고딕 Neo Bold 계열, 설명은 Regular. 한국어.
- 화면 안 UI는 **실제 앱과 똑같이**(Design v1 시안 그대로). 없는 기능을 그리지 말 것 — 위젯은 아직 없음.

## 3. 화면 속 예시 데이터 (모든 장에서 공통으로 사용)

- **교회** (노랑): 📌 느헤미야 4장 본문 관찰 정리 / 주보 원고 — 광고 3건 확인 (오후 3시) / 김 집사님 병원 심방 (오후 7시) / 금요 기도회 찬양 순서 보내기 / 수련회 장소 견적 비교 (어제 · 지남) / ~~헌금 봉투 주문~~
- **학교** (파랑): 10학년 성경 워크시트 인쇄 / 학부모 상담 일정 회신 (내일) / H11 수행평가 채점 (금 오후 5시) / ~~교사 기도회 기도제목 정리~~
- **성경공방** (분홍): 📌 느헤미야 강해 쇼츠 2편 편집 / 썸네일 문구 3안 / 설명란 타임스탬프 (오늘 밤)
- **집** (초록): 아이 피아노 픽업 (오후 4:30) / 세탁소 찾기 / 장보기 — 우유, 사과, 계란
- **설교 메모** (보라), **이번 주** (주황): 2~3줄씩
- 작성자 이름 자리에는 포스트잇 이름(교회·학교…)만. 실제 개인 이름·이메일은 넣지 말 것.
- 시간은 "10월 17일 (토) 오후 2:14" 고정.

## 4. 장별 구성

### iPhone (6장)
1. **"주머니 속 포스트잇 한 장"** — 교회 포스트잇 한 장 화면(I1). 종이가 화면 끝까지.
2. **"적고, 체크하면 끝"** — 체크 순간(체크 → 펜 취소선) 장면. 손가락 탭 위치를 옅은 원으로.
3. **"중요한 건 위에, 마감은 작게"** — 고정 구역 + 마감 표시(오늘 · 내일 · 지남 빨강)를 화살표 주석 2~3개로 짚어 줌.
4. **"옆으로 넘겨 교회 · 학교 · 집"** — 두 장이 넘어가는 중간 장면(A3), 아래 페이지 점.
5. **"마감 알림까지"** — 마감일 시트(I6) + 잠금 화면 알림 배너(M12) [완료] [1시간 뒤].
6. **"밤에는 어두운 종이"** — 다크 모드(I2).

### iPad (5장, 가로)
1. **"벽에 붙인 포스트잇 보드"** — 6장 보드(P1, 라이트). 가장 중요한 대표 이미지.
2. **"한 장에 집중"** — 크게 보기(P5), 오른쪽에 접힌 띠들.
3. **"모든 포스트잇에서 찾기"** — 위쪽 검색칸에 "느헤미야", 각 장에서 일치 글자 강조.
4. **"회의 중엔 옆에 띄워 두고"** — Split View로 다른 앱(Keynote 회의 자료)과 나란히(P6).
5. **"어두운 방에서도 편하게"** — 다크 보드 3장(P2).

### Mac (5장)
1. **"모니터 위에 붙여 두는 할 일"** — 바탕화면에 스티커 창 3~4장, 뒤에 작업 중인 앱(Pages 설교 원고)(M8).
2. **"쓰지 않을 땐 얇은 띠로"** — 접힌 띠 여러 개가 모니터 가장자리에 쌓인 모습(M2).
3. **"어떤 앱에서든 바로 적기"** — 메뉴 막대 빠른 입력 팝오버(M10), 단축키 ⌃⌥P 배지.
4. **"마감일은 우클릭 한 번"** — 마감일 팝오버(M6).
5. **"다크 모드 바탕화면에도 자연스럽게"** — 다크 스티커 6장(M9).

### 공통 대표 이미지 (선택, 1장 추가)
- **"맥 · 아이패드 · 아이폰, iCloud로 똑같이"** — 세 기기가 나란히, 같은 '교회' 포스트잇 내용이 세 화면에 동시에 보이고 가운데 작은 iCloud 체크 표시. 각 기기 규격 버전으로 하나씩.

## 5. 지켜 주세요

- App Store 심사 기준: 화면 속 UI는 실제 앱 기능만. 과장 문구("최고의", "1위") 금지.
- 헤드라인 12자 안팎, 설명 한 줄 25자 안팎. 모든 장에서 헤드라인 위치·크기 통일.
- 상태 막대(시간·배터리)는 깔끔하게(9:41, 배터리 가득). 노치·다이내믹 아일랜드는 실제 기기 모양.
- 라이트 장과 다크 장의 비율은 대략 4:1.
