# Postit 디자인 요청 (Claude Design 전달용)

아래 앱의 맥 · 아이패드 · 아이폰 화면과 위젯을 디자인해 주세요.
결과물은 SwiftUI로 그대로 구현할 예정이니, 애플 기본 컴포넌트와 SF Symbols로 만들 수 있는 범위에서 디자인해 주세요.

---

## 1. 앱 소개

**Postit**은 iCloud로 맥 · 아이패드 · 아이폰이 동기화되는 "포스트잇 할 일" 앱입니다.
일반 할 일 앱처럼 복잡한 목록·프로젝트 구조가 아니라, **책상에 붙여 둔 포스트잇 한 장**처럼 가볍게 적고 체크하는 것이 핵심입니다.

- 사용자: 목회자 겸 교사. 설교 준비, 심방, 주보, 학교 업무, 유튜브 채널 등 하루에 잡다한 일이 많음.
- 사용 방식: 맥에서는 모니터 두 대 위에 포스트잇 창을 항상 띄워 두고 일하면서 적음. 아이폰은 이동 중 확인·추가, 아이패드는 책상이나 회의에서 한눈에 보기.
- 언어: 한국어 UI (날짜 머리글 "Today", "2026.10.17(Sat)" 형식은 유지).

## 2. 지금의 디자인 (유지할 정체성)

- 종이 한 장이 곧 화면. 크롬(툴바·테두리)은 최소화.
- 종이 색 7가지: 노랑 #F9D977(기본), 주황 #FFC689, 분홍 #FFC4D6, 보라 #D9C8FF, 파랑 #BCDEFF, 초록 #C3EDC0, 회색 #E6E6E6
- 글자 색(잉크): #29261F, 작성자 이름 등 보조 글자: 검정 45%
- 여백: 좌우·아래 32pt, 위 40~44pt. 모서리 둥글기는 사용자 설정(0~40, 기본 20)
- 한 줄 구성: **[컬러 라벨 막대 5×14] 텍스트 ………… [체크박스]**
  - 라벨 색: 빨강 #ED544F, 주황 #F89433, 노랑 #D9B31A, 초록 #5CB866, 파랑 #458CE6, 보라 #9E6BD9
  - 완료: 취소선 + 40% 흐림 → 0.6초 뒤 그 날짜의 아래쪽으로 이동
- 맨 위 입력칸에 한 줄 적으면 맨 위에 추가. 날짜별 구분, 못 끝낸 일은 다음 날 Today로 이월.
- 맨 아래: 작성자 이름 + 동기화 상태 아이콘(동기화 전 / 중 / 완료).
- 글꼴은 사용자 설정: 기본·둥근·명조·고정폭·손글씨(Noteworthy), 크기·두께·줄 간격·항목 간격 조절.
- 맥: 테두리 없는 스티커 창 최대 6장, 항상 위, 위쪽 더블클릭으로 접기 → 이름과 남은 개수만 보이는 얇은 띠.

## 3. 디자인 목표

1. **세 기기 각각에 맞는 화면 구성.** 지금은 아이폰·아이패드가 "한 장을 화면 가득"뿐이라 아이패드의 넓은 화면을 못 쓰고 있습니다.
2. **새 기능을 넣되 포스트잇의 가벼움은 유지.** 기능이 늘어도 기본 화면은 지금처럼 단순해야 합니다. 부가 정보는 필요할 때만 드러나게.
3. **실제 종이 느낌 강화**와 **다크 모드** 추가.
4. 위젯과 맥 메뉴 막대에서도 같은 포스트잇으로 보이게.

## 4. 추가되는 기능 (UI 필요)

| 기능 | 디자인해야 할 것 |
|---|---|
| **마감일 · 알림** | 항목에 날짜/시간 지정 UI(입력 중 빠르게, 또는 항목 길게 누르기·우클릭). 줄 안에서 마감 표시(작게, 예: "오후 3시", "내일"), 오늘 마감 / 지난 마감 상태 표현. 알림 배너 모양 |
| **고정 · 순서 바꾸기** | 고정된 항목이 맨 위에 있다는 표시(핀 아이콘 또는 구분 영역). 끌어서 순서 바꿀 때의 들림·그림자·놓일 자리 표시 |
| **검색** | 지난 날짜까지 찾는 검색창 위치(맥: ⌘F 시 종이 위에 나타남, iOS: 아래로 당기면 나타남), 결과에서 일치 글자 강조, 결과 없음 상태 |
| **맥 메뉴 막대 입력** | 메뉴 막대 아이콘(남은 개수 표시 여부), 눌렀을 때 나오는 작은 포스트잇 팝오버: 입력칸 + 어느 포스트잇에 넣을지 + 오늘 할 일 몇 개 |
| **체크 애니메이션** | 체크 순간의 효과(체크 표시가 그려지고, 펜으로 긋듯 취소선이 지나가는 등), 이후 아래로 이동하는 동작. 과하지 않게 0.3~0.6초 |
| **종이 질감 · 그림자** | 은은한 종이 결(노이즈/섬유), 살짝 들린 모서리나 아래 그림자, 여러 장이 겹칠 때 깊이감. 글자 가독성을 해치지 않을 것 |
| **다크 모드** | 종이 7색 각각의 어두운 버전(형광 노트가 아니라 어두운 방에서 눈이 편한 톤), 잉크·라벨·체크박스 대비. 다크에서도 "종이"로 느껴질 것 |

## 5. 기기별 화면

### 맥 (macOS 15+)
- 스티커 창 1장: 펼친 상태 / 접힌 띠 / 입력 중 / 검색 중 / 마감일 지정 팝오버
- 여러 장이 모니터에 흩어져 있는 모습 (각기 다른 종이 색, 겹침과 그림자)
- 메뉴 막대 팝오버
- 설정 창 (지금: 폰트·크기·두께·줄 간격·항목 간격·모서리·종이 색·작성자 이름, 로그인 시 실행). 정리된 구성 제안

### 아이패드 (iPadOS 18+)
- **보드 화면:** 포스트잇 여러 장(최대 6장)을 한 화면에 나란히. 가로/세로 방향 각각, 장 수(1·2·3·4·6장)에 따른 배치
- 한 장을 크게 보기(탭해서 확대) ↔ 보드로 돌아가기
- Split View / Stage Manager처럼 창이 좁아졌을 때의 배치
- 포스트잇 추가·이름 바꾸기·색 바꾸기·삭제 진입점
- 키보드를 붙였을 때와 화면 키보드일 때의 입력칸 위치

### 아이폰 (iOS 18+)
- 한 장 화면 (지금처럼 종이가 화면 끝까지, 상태 막대 영역 포함)
- **옆으로 넘겨 포스트잇 바꾸기**, 지금 몇 번째 장인지 알 수 있는 표시
- 항목을 밀어서 완료(오른쪽) / 삭제·마감일(왼쪽)
- 키보드가 올라왔을 때 입력칸 위치 (한 손으로 빠르게 적기)
- 설정 시트

## 6. 위젯

| 위치 | 크기 | 내용 |
|---|---|---|
| 아이패드 홈 화면 | 중 · 대 · 특대 | 대: 포스트잇 한 장의 오늘 할 일 / 특대: 포스트잇 2~3장 나란히 |
| 맥 바탕화면 · 알림 센터 | 소 · 중 · 대 | 소: 남은 개수 + 다음 마감 / 중·대: 오늘 할 일 목록 |

- 위젯 안에서 체크박스를 눌러 바로 완료할 수 있음 (인터랙티브 위젯)
- 위젯도 종이 색·질감을 따름. 맥 바탕화면의 흐림 모드(배경 무채색 처리)와 iPadOS의 틴트/다크 홈 화면에서의 모습도
- 항목이 많을 때 "외 n개", 하나도 없을 때(모두 완료) 상태

## 7. 꼭 지켜 주세요

- **SwiftUI로 구현 가능할 것:** 시스템 폰트·SF Symbols·기본 컨트롤 위주. 커스텀 일러스트·복잡한 3D는 피해 주세요.
- 글자 크기·줄 간격·폰트는 사용자가 바꾸므로, 큰 글씨(예: 24pt)와 작은 글씨(13pt)에서도 깨지지 않게.
- 라벨 색은 색만으로 구분하지 않아도 되게(접근성), 체크박스·버튼 터치 영역 44pt 이상(iOS).
- 화면을 가득 채우는 기능 버튼은 피하고, 종이 위 빈 공간을 지킬 것.
- 다크/라이트 모두, 종이 7색 모두에서 잉크 대비가 충분할 것.

## 8. 받고 싶은 결과물

1. **디자인 토큰 표:** 라이트/다크 종이 색 7종, 잉크, 보조 글자, 라벨 6색, 그림자·질감 값, 여백, 모서리, 애니메이션 시간과 곡선
2. **화면 시안:** 위 5·6번의 각 화면 (기기별, 라이트/다크 대표 화면)
3. **컴포넌트:** 한 줄(기본·완료·고정·마감 있음·마감 지남·편집 중·드래그 중), 입력칸, 날짜 머리글, 체크박스, 라벨, 동기화 상태, 접힌 띠
4. **동작 설명:** 체크 애니메이션, 드래그 정렬, 아이폰 넘기기, 아이패드 보드↔한 장 전환을 단계별로 간단히
5. 각 디자인 결정의 짧은 이유 (왜 이 배치가 그 기기에서 더 효과적인지)
